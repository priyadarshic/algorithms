# Graphs and Trees Algorithms

A collection of Java implementations for common data structures and algorithms related to Graphs and Trees.

## Project Structure

- `src/main/java/com/algo/graphs`: Graph implementations and algorithms (BFS, DFS, Dijkstra, etc.).
- `src/main/java/com/algo/trees`: Tree structures and algorithms (Traversals, BST, AVL, etc.).
- `src/main/java/com/algo/common`: Shared utilities and interfaces.

## Getting Started

### Prerequisites

- Java 17 or higher
- Maven 3.6+

### Build and Test

```bash
mvn clean compile
mvn test
```
